# Cetaphil 倒置支撑座

纯 b4dcad 参数模型，不需要 CadQuery 或原始扫描文件即可生成。瓶盖闭合后倒放，使用时把整瓶向上拿起。座子靠瓶盖圆弧承托；下方贯通，不靠翻盖中央顶住瓶子。

## 生成和试配

从仓库根目录运行：

```sh
b4dcad preview src/misc/cetaphil_stand.py
b4dcad stl src/misc/cetaphil_stand.py ./stl --object fit_ring
b4dcad stl src/misc/cetaphil_stand.py ./stl --object stand
python3 -m unittest discover -s tests -p 'test_cetaphil_stand.py' -v
```

- `stand`：完整底座，116 × 90 × 38 mm；实体体积约 39.3 cm³。
- `fit_ring`：同一承托曲面的试配环，约 91.6 × 55.5 × 16 mm；约 10.2 cm³，先打印这个即可验证松紧。预览中放在底座旁边，单独导入切片器后居中即可。
- `show_assembly`：默认预览两件零件；不导出。
- `show_cap`：简化盖顶参考体，非可用瓶盖，不导出。可同时勾选 `stand`，用透明显示检查配合。

按导出方向、平底贴热床打印。默认模型的底座、试配环和排水槽均按不超过 45° 悬垂设计。排水槽的尖顶可能被切片器处理为很短的桥接。

拿着试配环，把闭合的瓶盖从大口放入，应能自然落座并轻松拔出；不要把试配环单独当作完整底座。试配通过后再打印底座，并实测装满瓶子时的稳定性。底面是硬质平面，没有集成防滑垫；湿台面的摩擦、瓶子重心和碰撞大小尚未实测。

## 参数

修改脚本末尾的 `settings = Parameters(...)`，或修改 dataclass 的默认值。所有长度单位均为 mm。

| 参数 | 默认 | 作用 |
|---|---:|---|
| `clearance` | 0.8 | 截面单侧偏移；太紧可加 0.2，太松可减 0.2，然后重打试配环 |
| `wall` | 3.0 | 水平截面壁厚；斜壁的法向厚度会略小 |
| `base_width`, `base_depth` | 116, 90 | 底座占地；增大短边尺寸可扩大前后方向的支撑范围 |
| `base_thickness` | 3.2 | 底板厚度 |
| `tip_gap` | 6.0 | 参考位置下盖顶离台面距离；实际落座后会略减小 |
| `cradle_start`, `cradle_end` | 16, 32 | 承托区相对倒置盖顶的高度；仅使用完整的扫描区域 |
| `width_scale`, `depth_scale`, `height_scale` | 1, 1, 1 | 仅缩放扫描形状，间隙及壁厚仍保持 mm 值 |
| `lead_in` | 0.6 | 最上面 2 mm 的额外单侧入口余量 |
| `drain_height` | 1.6 | 底面四条 V 顶排水槽，高度和半宽相同 |
| `exponent`, `segments` | 2.3, 128 | 超椭圆形状及每圈的离散段数 |

例：`Parameters(clearance=1.0, base_depth=100)`。不要为了调松紧而在切片器中整体缩放，否则壁厚、底座和排水槽都会一起变化。明显改变高度比例或承托区后，应重新检查悬垂。

本次没有实物卡尺校准，暂按扫描坐标的一个单位等于 1 mm。扫描中的盖子最宽处约 85 mm、前后约 47 mm；若实测不同，可先分别修改 `width_scale`、`depth_scale`。这些是整个盖子的粗略校准尺寸，承托口位于更靠近盖顶的位置，不能直接把它改成 85 × 47。

## 扫描与简化依据

来源：`~/Documents/Fused_20260915222715.stl`，174,301,384 bytes，3,486,026 个三角面。

SHA-256：`c42e6b515a9fa3337504ded1a5ab9c3b4947ba1d07597b12f8bc707f0993de63`。

扫描还包含一段不完整瓶身，整体长约 208 mm，因此没有拿整个网格直接布尔相减。分析时每 40 个三角面取一个，保留其三个顶点；用 PCA 初始定向，再按盖子截面中心的漂移修正约 5.14°。得到瓶盖朝下、瓶身朝上的坐标，读取各高度的截面宽厚，以指数 2.3 的超椭圆平滑包络。翻盖扣手的局部凹陷被填平，避免卡住、无需朝向对准扣手。

复核坐标变换如下；输入 `v` 为原始扫描顶点，矩阵各行依次为新 X、Y、Z 轴：

```python
center = [46.99655829788395, -18.718159352161425, -256.31927231191025]
axes = [
    [-0.991477643020046, 0.12415093993106778, -0.03947945675470084],
    [-0.09256073471520258, -0.45805963288529733, 0.8840892958915227],
    [-0.09167657160035927, -0.8802090188331512, -0.4656473873913449],
]
cap_xyz = (v - center) @ np.asarray(axes).T + [-0.14, 2.05, 76.6286264315803]
```

原始盖顶的轴向 0.01 百分位作为高度零点，排除个别噪点。`CAP_SECTIONS` 保存十个平滑截面，不保留原始三角面。参考体最下面 4 mm 用圆锥近似，仅用于显示，不用于承托面。

默认承托区（距盖顶 16–32 mm）共抽查 29,540 个扫描点，按 0.25 mm 高度分箱、取分箱较小截面的内腔验证，所有点均在内，最小边界余量约 0.23 mm。这只验证扫描样本与设计参考位置的几何关系，不代表打印公差或落座后的真实接触压力。开口向上逐渐变大，瓶盖会在重力下略下沉，直到与承托面接触。

完整底座为一个闭合实体，约 4,200 个三角面。测试覆盖封闭性、默认及调整参数后的悬垂、竖直取放、底部贯通排水和试配环与底座承托面的对应关系。默认非底面没有超过 45° 的悬垂；浮点放样接缝的极微小三角面允许总面积小于 0.0001 mm²。
